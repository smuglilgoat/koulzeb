# Agent session — 2026-09-10

## Goal

Plan and implement KoulZeb, a group dinner-planning app on Netlify: select
times + cuisine preferences + a restaurant list, cross them to rank a restaurant
and time, and support sessions shared by invite so others fill in their choices.

## Outcome

MVP implemented and verified locally. Not yet deployed to a live site.

## Decisions (approved defaults)

Link-based identity (no accounts) · per-session restaurant list · availability
from host-proposed time slots · ranked results with host confirmation · no
notifications · English UI · Netlify Blobs storage · 5s polling.

  restaurants from two participants, token redaction, result ranking, host-only
  decision, and decision persistence.
